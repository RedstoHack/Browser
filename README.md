# 👻 Amnesia — браузер с деменцией

Простой браузер для Android, который **каждый раз притворяется другим человеком** и **всё забывает**.

- 🎭 **Новая «личность»** вручную (кнопкой), при каждом входе в браузер или при **каждой загрузке страницы**
- 🧬 Реалистичные User-Agent (Chrome / Edge / Яндекс / Opera / Samsung / Firefox / Safari), **выдуманные несуществующие браузеры** или **свой UA**
- 📐 Подмена разрешения экрана **только для сайтов**: случайное, из списка или своё (`1280x720@1.5`)
- 🖥 **Десктоп-режим**: десктопный UA, широкий viewport, без признаков тач-скрина
- 🧹 **Деменция**: при запуске, выходе, сворачивании, смене личности или кнопкой «Забыть всё»

> IP-адрес браузер не скрывает: для этого нужен VPN или прокси (в настройках можно указать, например, `socks5://127.0.0.1:9050` для Orbot/Tor).

## Что подменяется

| Источник отпечатка | Что делает Amnesia |
|---|---|
| `User-Agent` (заголовок и `navigator.userAgent`, `appVersion`) | генерируется под личность |
| Client Hints: `Sec-CH-UA-*` и `navigator.userAgentData` | согласованы с UA (бренды, платформа, модель, версия) |
| `X-Requested-With` (выдаёт имя приложения) | убирается |
| `navigator.platform / vendor / productSub / oscpu` | под ОС личности |
| Ядра CPU, память, `maxTouchPoints` | подменяются |
| `screen.*`, `devicePixelRatio`, `outerWidth`, media queries `device-width` / `resolution` | подменяются |
| Видеокарта (`WEBGL_debug_renderer_info`) | подменяется |
| Canvas, WebGL `readPixels`, AudioContext, измерение шрифтов, ClientRects | детерминированный шум, свой для каждой личности |
| Часовой пояс (`Intl`, `getTimezoneOffset`, `Date.toString`, Temporal) и языки (+ `Accept-Language`) | по выбранному региону |
| WebRTC (утечка IP мимо VPN) | блокируется |
| Камеры и микрофоны, голоса синтеза речи | скрываются |
| Батарея, тип сети | подменяются |
| Плагины PDF, `window.chrome`, `navigator.webdriver` | как у настоящего браузера |
| iframe-«обход» через `contentWindow` | тоже подменяется |
| Подменённые функции | возвращают `function … { [native code] }` |
| Размер системного шрифта | не утекает (`textZoom = 100`) |
| Трекинг-параметры `utm_*`, `fbclid`, `gclid`, `yclid`… | вырезаются из ссылок |

Что стирает «деменция»: куки, localStorage, sessionStorage, IndexedDB, Cache Storage, Service Workers, HTTP-кэш (ETag-«суперкуки»), формы, HTTP-авторизацию, SSL-исключения, разрешения. При запуске папки WebView удаляются физически.

Кроме того: телеметрия WebView выключена, Safe Browsing выключен (можно включить), все запросы разрешений (камера, гео, микрофон) автоматически отклоняются, автозаполнение отключено, скриншоты запрещены (`FLAG_SECURE`), клавиатура в адресной строке в режиме «инкогнито».

## Cloudflare и другие антибот-проверки

Turnstile (ошибки **600xxx** = «обнаружено поведение бота») ищет противоречия в браузере. Поэтому:

- **Версия Chrome в UA всегда равна настоящей версии движка WebView.** Антиботы проверяют, что браузер умеет ровно то, что умеет заявленная версия.
- **Client Hints подменяются на уровне WebView** (если версия WebView это поддерживает). Тогда заголовки, `navigator.userAgentData` и Web Workers показывают одно и то же.
- **Во фреймах проверок** (challenges.cloudflare.com, hCaptcha, reCAPTCHA) подмена JS **не применяется никогда**.
- **Сторонние куки** автоматически разрешаются, пока на странице идёт проверка: без них Turnstile не проходит. Если проверка всё равно упала с первого раза, нажмите «Повторить».
- **Переходы, которые сайт делает сам на тот же домен**, личность не меняют. Иначе после проверки Cloudflare новый UA снова её запускает, и получается цикл.
- Если проверка всё равно не проходит, используйте **меню → 🛡 Совместимость для сайта**: на этом сайте подмена JS отключится, но UA, Client Hints и «деменция» продолжат работать. Если проверка висит дольше 8 секунд, браузер сам предложит это включить.
- Режимы «Firefox/Safari» и «выдуманный браузер» Cloudflare распознаёт почти всегда, потому что движок у WebView Chromium. Для сайтов за Cloudflare выбирайте «Реалистичный (Chromium)».
- Cloudflare сам советует отключать VPN: «грязный» IP тоже даёт ошибку 600010, отпечаток тут ни при чём.

## Проверить себя

Меню → **🧪 Проверить отпечаток**: CreepJS, BrowserLeaks, Cover Your Tracks (EFF), AmIUnique, Pixelscan. Сравните результаты до и после **🎭 Новая личность**.

## Честные ограничения

Полной неотличимости от настоящего Chrome на WebView добиться нельзя. Знать об этом стоит:

- Движок всегда Chromium. Профиль «Firefox» или «Safari» продвинутые тесты (CreepJS) распознают по набору возможностей. Самый незаметный режим — **«Реалистичный (Chromium-браузеры)»**.
- Выдуманные браузеры делают вас уникальным, но непохожим ни на кого. Это хорошо против связывания визитов, но заметно.
- Шум canvas/audio тесты вроде CreepJS могут распознать как подмену («lies»). Отпечаток при этом всё равно разный у каждой личности.
- Не подменяются: значения внутри Web Workers, перечисление шрифтов через размеры DOM-элементов, `Date#getHours` (часовой пояс подменён для форматирования и смещения), TLS/HTTP2-отпечаток сети.
- `Accept-Language` подменяется только для основных переходов. Для картинок и скриптов идёт язык системы, поэтому лучше выбирать регион с тем же языком, что и в системе.
- Режим «при каждой загрузке страницы» вместе с «Забывать при смене личности» означает, что залогиниться никуда не получится. Так и задумано 🙂
- Нужен актуальный «Android System WebView» (Google Play). На старых версиях скрипт внедряется позже и часть значений может утечь: приложение предупредит об этом в «Текущий отпечаток».

## Сборка

### Через GitHub (рекомендуется)

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions**. Сборка запускается сама при каждом push.
3. Готовый APK лежит в **Actions → последний запуск → Artifacts**.
4. Чтобы получился **Release** с APK: `git tag v1.0.0 && git push --tags`.

### Подпись своим ключом (чтобы обновления ставились поверх)

Без ключа APK подписывается временным debug-ключом, который на GitHub каждый раз новый, поэтому обновление придётся ставить с удалением старой версии. Чтобы этого избежать, один раз создайте ключ:

```bash
keytool -genkeypair -v -keystore release.jks -keyalg RSA -keysize 4096 -validity 10000 -alias amnesia
base64 -w0 release.jks > release.jks.b64      # на macOS: base64 -i release.jks
```

Затем добавьте в **Settings → Secrets and variables → Actions** секреты:

| Secret | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `release.jks.b64` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `amnesia` |
| `KEY_PASSWORD` | пароль ключа |

Сам `release.jks` в репозиторий **не** кладите (он уже в `.gitignore`).

### Локально

Нужны JDK 17 и Android SDK (проще всего через Android Studio):

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

## Устройство проекта

```
app/src/main/
├── assets/spoof.js            ← движок подмены (внедряется до скриптов страницы во все фреймы)
└── java/com/amnesia/browser/
    ├── MainActivity.kt        ← браузер, смена личности, жизненный цикл «деменции»
    ├── ProfileGenerator.kt    ← генерация согласованных личностей (версии считаются от даты)
    ├── Profile.kt             ← личность (JSON)
    ├── SpoofScript.kt         ← сборка JS из шаблона + настроек
    ├── WebCompat.kt           ← Client Hints и X-Requested-With для новых WebView
    ├── Cleaner.kt             ← стирание всех данных
    ├── UrlUtil.kt             ← адресная строка, чистка трекинг-параметров
    ├── Prefs.kt / SettingsActivity.kt
```

Минимальная версия Android — 8.0 (API 26). Лицензия — MIT.
